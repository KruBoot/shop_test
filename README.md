# BladeMaster Landing Page

เว็บไซต์ Landing Page แบบ Single Page สำหรับร้าน **คมมีด BladeMaster** ออกแบบในสไตล์ **Modern Military + Material Design 3** เน้นความเรียบหรู ทันสมัย รองรับทุกอุปกรณ์ และสามารถเปิดใช้งานได้ทันทีผ่านไฟล์ `index.html`

---

## Project Information

**ชื่อร้าน**

> คมมีด BladeMaster

**สโลแกน**

> มีดคม ใช้งานได้จริง ราคาเอื้อมถึง

**รายละเอียดร้าน**

ร้านขายมีดคุณภาพสูง ทั้งมีดครัวญี่ปุ่น มีดพก มีดล่าสัตว์ และมีดพิเศษหลากหลายรุ่น เน้นวัสดุสแตนเลสและเหล็กคาร์บอนคุณภาพสูง ผ่านการชุบแข็งอย่างดี แข็งแรง ทนทาน และปลอดภัย เหมาะสำหรับเชฟ มือใหม่ นักเดินป่า และนักล่า
